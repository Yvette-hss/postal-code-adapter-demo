# 多国邮政编码验证系统

## 项目简介

本项目是 Java 软件设计与体系结构课程实验，通过适配器设计模式扩展邮政编码验证功能，支持中国、美国和加拿大的邮编格式校验。

## 技术栈

- Java
- Swing
- 正则表达式
- Adapter Pattern（适配器模式）

## 核心功能

1. 支持选择不同国家进行邮编格式校验。
2. 通过适配器模式扩展中国六位数字邮编校验。
3. 提供图形界面输入与验证结果提示。
4. 保留原有美国、加拿大邮编验证功能。

## 测试结果

实验报告记录了中国、美国、加拿大各 2 条有效与无效邮编测试，共 6 条测试样例，结果均符合预期。

## 运行说明

本项目为 Java 课程实验项目。

使用已配置 JDK 的 Java IDE 打开源代码，按照项目实际的入口类启动图形界面程序。
